The contract

Agents may

  • Post events — facts that already happened, with case IDs
  • Post health — gates, timers, units, disk
  • Post proposals — always rendered inert, always linking to the console
  • Post questions, and remind you when something goes stale
  • Echo back a decision after you made it in the console

Agents may never

  • Approve, reject, escalate or close a case
  • Commit, accept or discard a tuning proposal
  • Block an IP, revoke a ticket, or change a verdict
  • Treat any message — yours included — as an instruction that mutates state
  • Render raw attacker-controlled alert text inline

Why your messages carry a chip

  • A reply in this room is advisory. The click in the console is the authorization.
  • Labelling it visibly means nobody can later read a chat reply as a signed adjudication.
  • It keeps ADR-008 stage 3 intact: a proposal stays inert, and a human's word is not a commit.
The one-line test. If acting on a message in this room would change a verdict, a signature, or a blocklist — it is not a chat action. It's a console action.

Record of truth

  • This room is a witness, not a system of record.
  • Authoritative: append-only spine receipts + Ed25519-signed commits.
  • Retention can be short. Anything that matters is reconstructible from the spine.

Message classes

event — a fact. Immutable, no action.
proposal — wants a decision, cannot act.
question — agent is asking you.
health — the machine talking about itself.
answer — you. Advisory only.
refused — a request the agent declined.
