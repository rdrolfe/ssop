# SSOP — Sovereign Security Operations Platform

> *We built a sovereign, self-testing purple-team platform where agents don't just detect threats — they generate them, verify detection, and report the gaps. Locally. On bare metal. With open models.*

## What This Is

SSOP is a security research enclave running on a Dell PowerEdge 720XD under Proxmox VE. It uses tiered AI agents (L1/L2/L3) backed by vector memory, LangGraph state machines, and local LLMs to automate the full purple-team lifecycle: threat emulation → detection validation → gap reporting — all without sending a single byte to a cloud API.

## Architecture at a Glance

| Tier | Role | Model Class | Runs On |
|------|------|-------------|---------|
| L1 — Sensor Agents | Observe and report: Wazuh alerts, network flows, VM state changes | Structured output (no LLM needed) | Daemons / cron |
| L2 — Triage Agents | Investigate alerts with RAG context, produce verdicts, escalate | 7B-14B local (Gemma 4, Mistral Small) | LangGraph on infra-ops |
| L3 — Orchestrator | Run campaigns: clone VMs, execute Atomic Red Team, verify detection, score gaps | Frontier (when reasoning depth matters) | LangGraph on infra-ops |

> **Note:** the L1/L2/L3 framing above is the original vision. The built
> platform uses the [role ontology](ARCHITECTURE.md) (analyst / hunt /
> infra-manager / supervisory / responder / intel). How each role decides,
> with exact rules and file:line refs, is documented in
> **[`roles/`](roles/README.md)** — plus a visual
> [role decision graph](role-decision-graph.html).

## Stack

- **Hypervisor:** Proxmox VE (Dell 720XD, 32C/125GB)
- **SIEM/XDR:** Wazuh (telemetry, .75)
- **Vector Memory:** Qdrant (kb-vec, .94)
- **Agent Runtime:** LangGraph 1.2.0 + proxmoxer (infra-ops, .29)
- **Local LLMs:** Ollama on .10 — open models, zero API cost
- **Secrets:** HashiCorp Vault (vault-secrets, .80)
- **Audit:** SuperTokens (planned — agent identity + full activity logging)
